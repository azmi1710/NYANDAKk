Langkah Customer Langkah Kurir Aturan Kunci Bisnis
1CUSTOMER
Bikin order Pilih layanan (Beliin / Antar / Lainnya), isi detail barang, zona asal → tujuan, foto bila perlu
2CUSTOMER
Tarif otomatis Sistem baca tabel zona — ongkir flat tampil sebelum order dikirim, tanpa tawar-menawar
3KURIR
Ambil order Order muncul di papan kurir online di zona itu — first-come-first-serve: tercepat klik AMBIL yang dapat
4KURIR
Eksekusi + bukti Status DIPROSES: belanja / jemput barang — wajib foto struk sebelum boleh DIANTAR
5KURIR
Diantar Status DIANTAR ke tujuan — customer & admin melihat pergeseran status secara real-time
6CUSTOMER
Bayar COD + rating Bayar harga barang + ongkir di tempat — kurir tandai SELESAI, order masuk rekap, customer kasih rating 1–5
ATURAN KUNCI
Chat aktif sejak kurir mengambil (langkah 3) sampai order selesai (langkah 6)  ·  Batal: gratis sebelum langkah 3, Rp 5.000 setelahnya  ·  Sengketa barang: wajib foto bukti, diputuskan admin  ·  Jam layanan: 06.00–20.00 WIB  ·  Ongkir masuk kas kurir saat serah terima, harga barang utuh ke penjual
